# AI Voice Assistant

A modern realtime AI Voice Assistant built using Next.js, Groq AI, LiveKit Cloud, and Vercel.

## Features

- Realtime AI Chat
- Voice Input
- Voice Replies
- AI Personalities
- Typing Animation
- Chat History Save
- Premium Light UI
- Responsive Design
- Public Deployment

## Tech Stack

- Next.js
- TypeScript
- Tailwind CSS
- Groq API
- LiveKit Cloud
- Vercel
